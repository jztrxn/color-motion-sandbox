Purpose:
The purpose of this project is to develop an application to explore whether adding direction cues can provide additional encoding information to color, with the goal to helping color-deficient individuals. 

Example:
For example, the most common color blindness is red-green, where indiviudals cannot distinguish between these two colors. Is it possible that adding a directional cue (such as right direction to red and left direction to green), these individuals can begin to distinguish between red and green? 

Goal:
I want to create a simple sandbox application that applies a motion element to color. This project should input any image (color or grayscale), analyze the color around each pixel, and apply motion in a reliable and replicable way. 

First Attempt:
Initial first attempts will apply a moving sine grating with the direction according to the location of that color on a color wheel (360 degrees). Hue can correspond to motional direction, saturation can apply to motion speed. 


I want you to create a sandbox where I can play around with as many different parameters as I can. I can play with hue/direction, saturation/speed, grating size, bar size, bar color, as many parameters that are reasonably useful. This sandbox should have code written in an easy way for humans to interpret, make it visible, easily editable. It should also have a simple usable interface to adjust all these parameters. It should also be able to easily upload any image.
